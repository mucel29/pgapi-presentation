# Stanford Bunny

Source: Stanford University Computer Graphics Laboratory, Stanford 3D Scanning Repository.

- Repository and usage terms: https://graphics.stanford.edu/data/3Dscanrep/
- Download: https://graphics.stanford.edu/pub/3Dscanrep/bunny.tar.gz
- Mesh: bunny/reconstruction/bun_zipper_res4.ply (decimated reconstruction).
- Local JSON stores the original mesh vertices and faces, uniformly scaled and centered for this educational BVH demonstration. No runtime network request.

Reconstruction README: these files reconstruct range images with the zipper program; the res variants are decimated versions suitable for interactive rendering. Original data acquired using a Cyberware 3030MS scanner.
